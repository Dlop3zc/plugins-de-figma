# Plugins de Figma

Colección de plugins de Figma y sus herramientas de apoyo. Cada plugin vive en su propia carpeta con su README.

| Plugin | Descripción |
|---|---|
| [`json-dashboard/`](json-dashboard/) | Consulta servidores internos de prueba a través de un proxy local (Flask) y genera un dashboard con Auto Layout en el lienzo a partir de cualquier JSON. |
